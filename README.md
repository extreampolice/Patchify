# Patchify
Patchify is an Experimental Project Wingman Mod Merger made using UAssetAPI.

This Project was 100% written by AI(Asian Intelligence).

***This project is NOT feature complete. Additional features such as Plane Filtering, Custom Patch Generation and GUI Implementation are in plan***

# How to build
1.Open Patchify.slnx in Visual Studio.

2.Install UAssetAPI in NuGet.

3.Place your ~mods folder in the same folder where your executable will be.

4.This program takes your Project Wingman's "pakchunk0-WindowsNoEditor.pak" file's FullPath(locate the file, right click and copy path). so you should copy paste its FullPath into the command line argument option in Visual Studio.

4.Build and Run

# How to use
***%WARNING% this program take up as much RAM as your mod file's combined size.**

1.Launch cmd from the Patchify Folder.

2.Patchify.exe "[pakchunk0-WindowsNoEditor.pak FullPath]"

3.The combined .pak file will be in the ~RESULT folder.

4.The Full List of Changes will be in the ~patches/combined.json

4.place the combined.pak file into the PW's ~mods folder
